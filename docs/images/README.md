# Preview provenance

`control-panel.png` is a browser screenshot of the companion
[Microduck Control panel](https://github.com/tessel-la/robo-boy-microduck-control-panel),
release `v1.1.0`, with sample telemetry. That panel is MIT licensed; its notice is
preserved in [`CONTROL-PANEL-LICENSE`](CONTROL-PANEL-LICENSE).

`mock-camera.jpg` is produced directly by this integration's
[`MockBackend.jpeg_frame()`](../../src/mujoco_warp_locomotion_sim/mock_backend.py)
after 2 s of synthetic motion. Its grid and status text are generated by MIT-licensed
code. It does not load or render CAD, meshes, policy weights, or training assets.

No restricted Microduck model appears in these documentation previews. This avoids
relying on an unspecified Creative Commons version or assuming that a non-commercial
model grant permits promotional rendering. The model terms in
[`THIRD_PARTY.md`](../../THIRD_PARTY.md) remain unchanged. These previews do not show
real physics or imply endorsement by Pollen Robotics.

The panel's runtime theme comes from [Robo-Boy](https://github.com/tessel-la/robo-boy),
licensed under Apache-2.0. Its license is preserved in
[`ROBOBOY-LICENSE`](ROBOBOY-LICENSE).
